Facebook Accounts

Each account = one Facebook login in its own Chrome profile, owning a group of ZIPs. Posts auto-route by ZIP to the right account.

Setup per account: open a separate Chrome profile (chrome://profiles → Add), log into that Facebook account, install this extension there, then in the extension popup pick this account under “This Chrome profile posts as.”

Auto-Pilot

Auto-posts your templates on a daily schedule, rotating through the ones you pick — hands-free.

⚠️ Keep it safe: Facebook bans accounts that post too aggressively. Start with 1–3 posts/day. Auto-Pilot only runs while your PC is on, Chrome is open, and you're logged into Facebook.

Publish Queue

The extension background script checks this queue every 20 seconds and opens a Facebook tab to auto-post each job. Make sure Chrome is open and you are logged in to Facebook.

Form Captures

Use the extension’s “🔧 Capture Form (debug)” button on the Facebook create page (open the Category or ZIP dropdown first), then copy the latest capture below and paste it to your assistant to get exact selectors.

Automation Logs

Every action and error from the listing automation is recorded here — useful for seeing exactly where a publish stopped.

Marketplace Bot Activity

Live view of the Marketplace → chatbot bridge: inbound buyer messages the extension forwarded to your existing chatbot, the replies sent back, and any errors. Auto-refreshes every 5s. Keep a logged-in Chrome window open on the Marketplace inbox for the bot to send.
